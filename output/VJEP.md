## 1. V-JEPA 的整体框架

V-JEPA 是一种视频自监督学习方法。它不要求模型逐像素重建未来画面，而是根据可见视频上下文，预测被遮挡区域或未来区域在表示空间中的特征。训练目标主要约束物体、动作和时空关系等抽象信息，而不是复制像素级细节。

系统由上下文编码器、EMA 目标编码器和 Transformer Predictor 组成。上下文编码器读取可见区域并生成上下文表示；目标编码器读取完整目标视图并生成监督表示；Predictor 接收上下文表示并预测目标区域表示。

核心关系如下：

    Z_C = f_θ(V_C)
    Z_T = f_θ̄(V_T)
    Ẑ_T = p_φ(Z_C)
    L_JEPA = ℓ(Ẑ_T, sg(Z_T))

其中，V_C 是上下文视频，V_T 是目标视频，f_θ 是上下文编码器，f_θ̄ 是 EMA 目标编码器，p_φ 是 Predictor，sg 表示停止梯度。目标编码器通过指数滑动平均更新：

    θ̄(t+1) = m · θ̄(t) + (1 − m) · θ(t)

当前工程实例中，编码器采用 ViT-L/16，包含 24 个 Transformer block、1024 维隐藏表示和 16 个注意力头；Predictor 包含 12 个 block，内部预测维度为 384，末端再投影回 1024 维目标特征。

## 2. V-JEPA 的完整数据流

### 2.1 视频输入与预处理

原始输入是一个批量视频片段：

    V ∈ R^(B × T × H × W × 3)

其中 B 是批量大小，T 是帧数，H × W 是帧分辨率，3 表示 RGB 通道。当前典型配置使用 16 帧、224 × 224 分辨率。视频进入模型前经过裁剪、缩放和归一化，使所有样本具有统一的时空尺寸与数值范围。

### 2.2 Tubelet Embedding 与 token 化

V-JEPA 不是逐帧独立提取二维图像特征，而是同时沿时间和空间切分。ViT-L/16 配置中，时间方向每 2 帧组成一个 tubelet，空间方向使用 16 × 16 patch。

因此 token 数量为：

    N = (T / 2) × (H / 16) × (W / 16)
      = 8 × 14 × 14
      = 1568

每个 2 × 16 × 16 × 3 的 tubelet 展平后，经线性投影映射到编码器隐藏维度。经过位置编码和 ViT 编码器后，视频表示为：

    Z ∈ R^(B × 1568 × 1024)

一个 token 不是单帧中的二维小块，而是连续两帧中同一空间 patch 的联合表示。token 索引同时对应时间位置、空间行位置和空间列位置，因此编码器输出已经融合空间信息和时间信息。

### 2.3 构造上下文视图与目标视图

训练样本按照时空 mask 划分为上下文区域和目标区域。上下文通常包含较早帧或当前可见区域，目标通常包含后续帧或被遮挡的时空块。上下文编码器只接收上下文区域；目标编码器接收完整目标视图，编码后再根据目标 mask 选取目标 token。

这一步人为制造信息缺失条件，使模型必须从已有时空信息进行推断，而不是直接读取目标区域。可以概括为：

    早期/可见视频区域
        → 上下文表示
        → 后续/隐藏区域的目标表示

### 2.4 上下文编码器路径

上下文视频 V_C 经过预处理、tubelet 切分和 embedding，形成上下文 token。上下文编码器 f_θ 对这些 token 进行多层时空 Transformer 运算，输出上下文表示：

    Z_C = f_θ(V_C)

如果保留完整 token，基础输出尺寸为 B × 1568 × 1024；如果先按上下文 mask 选取子集，序列长度会变化，但每个 token 的特征维度仍为 1024。上下文编码器参数 θ 通过 JEPA 损失反向更新。

### 2.5 EMA 目标编码器路径

目标视图 V_T 进入目标编码器：

    Z_T = f_θ̄(V_T)
    Z_T^M = Select_M(Z_T)

其中 M 表示目标 mask，Z_T^M 是真正参与监督的目标 token。目标编码器不接收当前 JEPA 损失的直接反向梯度，而是在训练步骤后按照以下规则更新：

    θ̄(t+1) = m · θ̄(t) + (1 − m) · θ(t)

因此目标表示是一个缓慢变化的参照，避免上下文编码器和 Predictor 通过瞬时参数变化或简单复制输入来降低损失。

### 2.6 上下文表示进入 Predictor

上下文编码器输出先经过维度变换，进入 Predictor 的内部预测空间。当前 Predictor 内部维度为 384，所以输入可以表示为：

    X₀ ∈ R^(B × 1568 × 384)

随后，Predictor 根据目标 mask、位置编码和 mask token 组织序列，使每个待预测位置具有对应的时空位置信息。此时 Predictor 不再处理原始 RGB 视频，而是在上下文 token 上完成特征预测。

### 2.7 逐层经过 Transformer Predictor

Predictor 包含 12 个串行 Transformer block。第 l 个 block 的输入记为 X_l。QKV 联合投影为：

    Y_l = X_l · W_QKV,l + b_l

当前标准尺寸为：

    X_l       ∈ R^(B × 1568 × 384)
    W_QKV,l   ∈ R^(384 × 1152)
    Y_l       ∈ R^(B × 1568 × 1152)

随后沿最后一维拆分：

    Q_l, K_l, V_l ∈ R^(B × 1568 × 384)

重排为多头形式后，执行缩放点积注意力：

    Attention(Q_l, K_l, V_l)
      = Softmax(Q_l · K_lᵀ / √d_h) · V_l

注意力结果经过输出投影、第一次残差连接，再经过 LayerNorm、MLP/FFN 和第二次残差连接：

    X_(l+1) = Block_l(X_l)

因此第 l+1 层输入依赖第 l 层输出，第 12 个 block 的输出依赖前面所有 block。这种串行依赖是 Predictor 进行深层特征变换和误差累积的来源。

### 2.8 Predictor 末端输出

12 个 block 完成后，Predictor 依次执行末端归一化、目标 token 选择和投影：

    Ẑ_T = Proj_pred(Select_M(LN(X_12)))

末端投影把 384 维 Predictor 表示映射回目标编码器特征维度，例如 1024 维。因为只保留目标位置，Ẑ_T 与 Z_T^M 在 token 数量和特征维度上对应。

### 2.9 特征空间损失与参数更新

对目标 token 的预测特征和目标编码器特征计算差异。采用 L1 特征损失时：

    L_JEPA = (1 / (|M| · D)) × Σ_(i∈M) Σ_(d=1…D) |ẑ_(i,d) − zᵀ_(i,d)|

其中 M 是目标 token 集合，D 是目标特征维度。梯度经过 Predictor 传回上下文编码器；目标编码器不接收这条反向梯度，而是在训练步骤后通过 EMA 更新。

完整训练顺序是：视频预处理 → tubelet/token 化 → 生成上下文视图和目标视图 → 上下文编码器提取 Z_C → EMA 目标编码器提取 Z_T → Predictor 根据 Z_C 预测目标特征 → 与目标特征计算损失 → 反向更新上下文编码器和 Predictor → EMA 更新目标编码器。

### 2.10 IntPhys 评估阶段

评估时不更新参数。观察到的上下文帧经过上下文编码器和 Predictor，得到未来区域的预测特征；真实未来表示由目标编码器或预先提取的未来特征提供。二者差异作为 surprise：

    S = ℓ(Ẑ_T, Z_T)

物理上合理的事件通常具有较小特征差异，违反学习到的时空规律的事件通常具有较大差异。工程中可对 token、通道或空间位置使用 mean、max 或 top-k 聚合得到视频级分数，再用 AUROC 区分 possible 与 impossible 样本。

## 3. FSONN 如何替代 Transformer Predictor

### 3.1 替代范围

对每个指定 Predictor block，只替换固定权重的 QKV 投影：

    Y_l = X_l · W_QKV,l
    Ŷ_l = O_l(X_l; ψ_l)

其中 O_l 是第 l 个 block 的光学 QKV 模块，ψ_l 是该 block 独立的光学参数。若原始 QKV 有 bias，则电子端继续添加：

    Y_l,final = Ŷ_l + b_l

不同 Predictor block 不共享光学参数；同一个 block 的三个时间槽共享一套光学参数。

### 3.2 三时间槽输入与输出

光学模块接收：

    X ∈ R^(B × 1568 × 384)

沿 token 维切分：

    X₁ = X[:, 0:523, :]
    X₂ = X[:, 523:1046, :]
    X₃(real) = X[:, 1046:1568, :]

第三槽只有 522 个真实 token，因此补充一个全零 token：

    X₃ = concat(X₃(real), 0) ∈ R^(B × 523 × 384)

三个时间槽都使用同一套光学 QKV 参数，分别输出：

    Ŷ_i ∈ R^(B × 523 × 1152),  i = 1, 2, 3

拼接后：

    Ŷ_pad = concat(Ŷ₁, Ŷ₂, Ŷ₃) ∈ R^(B × 1569 × 1152)

再裁剪：

    Ŷ = Ŷ_pad[:, 0:1568, :]

裁剪在 Q/K/V 拆分和 attention 之前完成，因此补零 token 不进入 QKᵀ、Softmax、AV 或监督损失。

### 3.3 光学 token 串扰

原始电子 QKV 对每个 token 独立执行固定矩阵映射：

    y_t = x_t · W_QKV

自由空间传播会产生衍射、边界扩散和空间场耦合。若布局或探测读出设计不理想，一个 token 的输出可能混入其他 token 的输入，更接近：

    ŷ_t ≈ Σ_s A_(t,s) · x_s

原始逐 token 语义希望非目标位置耦合较小，即 A_(t,s) ≈ 0（s ≠ t）。统一网格、固定布局、三槽重组和 attention 前裁剪只能保证张量尺寸与顺序正确，不能自动消除光学串扰。

### 3.4 替代后仍由电子端完成的计算

光学 QKV 输出恢复为原始张量后，继续执行：

    光学 QKV → Q/K/V 拆分 → QKᵀ → 缩放与 Softmax → AV
    → 输出投影 → LayerNorm、残差、MLP/FFN

本阶段不替换 QKᵀ、Softmax、AV、输出投影、LayerNorm、残差连接和 MLP/FFN，也不修改上下文编码器或目标编码器中的 attention。

### 3.5 电子基准与光学 Predictor 的训练关系

电子基准 Predictor 使用官方 checkpoint，并保持 eval() 与 no_grad()；光学 Predictor 从相同的官方 Predictor 初始化，只替换指定 block 的 QKV，并冻结其余电子参数。单卡条件下，两条路径在同一张 GPU 上依次执行，这只是硬件调度方式。

两条路径只有 Predictor 初始输入相同，之后分别经过各自的 12 个 block。不能把电子基准路径第 l 层输出直接作为光学路径第 l 层输入，否则会掩盖前面光学 QKV 造成的分布变化。当前策略只将最后一个 block 的损失用于反向传播：

    L_train = L_(L−1)

前面各层损失只记录为诊断指标，不与最后一层损失相加，也不执行多次优化器更新。光学 Predictor 各 block 之间不 detach()，因此最后一层损失可依据链式法则传回前置光学模块；被冻结的电子参数只传递梯度，不更新自身数值。

## 4. 光学 Transformer 的其他替代方向

光学神经网络适合固定权重线性变换、向量矩阵乘法和高吞吐场传播。后续可以研究：将 Q、K、V 分开替代；用光学矩阵乘法实现动态的 QKᵀ 或 AV；替代注意力输出投影；替代 MLP/FFN 中的全连接层；以及替代 Predictor 末端的 predictor_proj。

QKᵀ 和 AV 依赖输入动态生成的矩阵，需要额外处理位置配对、缩放、Softmax、噪声和精度，通常比固定权重 QKV 更困难。更大范围的全光学 Transformer 还需要解决非线性激活、存储、反馈、可编程性、探测噪声和误差累积等问题。当前选择 QKV 作为第一步，是因为它具有固定权重、明确输入输出尺寸和稳定的电子接口，同时能把实验风险集中到光学线性映射误差与 token 串扰两个关键问题上。
